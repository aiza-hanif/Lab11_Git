Storage Estimator



Purpose



This Python program estimates storage size by converting gigabytes (GB) into megabytes (MB).



How to Run



Install Python 3.



Open Git Bash or Command Prompt in the project folder.



Run: python storage\_estimator.py



Enter a storage value in GB when prompted.



Example Input and Output



Input:

Enter storage in GB: 2



Output:

2048.0
